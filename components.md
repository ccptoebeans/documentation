The carbon engine is organized as a set of components, each providing specific functionality. In order to assemble a
full runtime environment, [a process called "Update Binaries"](updatebinaries.md) is currently used by games built with 
Carbon.

The following table provides an overview of available open-source components and their purpose.

| Component                | Description                                                                                                        | Repository                                                                                                                                     |
|--------------------------|--------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------|
| audio                    | The audio engine for the Carbon Engine                                                                             | [<img src="images/github-mark.svg" alt="GitHub repository" width="32" height="32">](https://github.com/carbonengine/audio/)                    |
| blue                     | Blue is the glue between Python and C++                                                                            | [<img src="images/github-mark.svg" alt="GitHub repository" width="32" height="32">](https://github.com/carbonengine/blue/)                     |
| blueexposure             | Python exposure for C++ code as well as some utilities                                                             | [<img src="images/github-mark.svg" alt="GitHub repository" width="32" height="32">](https://github.com/carbonengine/blueexposure/)             |
| core                     | Provides generic low-level functionality and cross-platform abstractions for system calls                          | [<img src="images/github-mark.svg" alt="GitHub repository" width="32" height="32">](https://github.com/carbonengine/core/)                     |
| d3dinfo                  | Python-exposed library to detect DirectX capabilities of the PC                                                    | [<img src="images/github-mark.svg" alt="GitHub repository" width="32" height="32">](https://github.com/carbonengine/d3dinfo/)                  |
| db                       | Wrapper for game server database access                                                                            | [<img src="images/github-mark.svg" alt="GitHub repository" width="32" height="32">](https://github.com/carbonengine/db/)                       |
| destiny                  | Core game world simulation engine for MMOs whose titles start with Eve                                             | [<img src="images/github-mark.svg" alt="GitHub repository" width="32" height="32">](https://github.com/carbonengine/destiny/)                  |
| exefile                  | Elements used to build the final exefile executable                                                                | [<img src="images/github-mark.svg" alt="GitHub repository" width="32" height="32">](https://github.com/carbonengine/exefile/)                  |
| geo2                     | Python math library built on top of Microsoft DirectXMath                                                          | [<img src="images/github-mark.svg" alt="GitHub repository" width="32" height="32">](https://github.com/carbonengine/geo2/)                     |
| grpc                     | Provides a base for creating project specific Python gRPC modules                                                  | [<img src="images/github-mark.svg" alt="GitHub repository" width="32" height="32">](https://github.com/carbonengine/grpc/)                     |
| imageio                  | Library handling basic bitmap image manipulation and serializing images to and from some common image file formats | [<img src="images/github-mark.svg" alt="GitHub repository" width="32" height="32">](https://github.com/carbonengine/imageio/)                  |
| imagetools               | Python extension and C++ image processing library used for loading, manipulating, and compressing image data       | [<img src="images/github-mark.svg" alt="GitHub repository" width="32" height="32">](https://github.com/carbonengine/imagetools/)               |
| ime                      | exposes native input method editor functionality to Python                                                         | [<img src="images/github-mark.svg" alt="GitHub repository" width="32" height="32">](https://github.com/carbonengine/ime/)                      |

| math                     | Provides some basic math utilities for vectors, planes, quaternions etc.                                           | [<img src="images/github-mark.svg" alt="GitHub repository" width="32" height="32">](https://github.com/carbonengine/math/)                     |
| mesh                     | Library for 3D mesh manipulation, animation and storage                                                            | [<img src="images/github-mark.svg" alt="GitHub repository" width="32" height="32">](https://github.com/carbonengine/mesh/)                     |
| parser                   | Math expression parser                                                                                             | [<img src="images/github-mark.svg" alt="GitHub repository" width="32" height="32">](https://github.com/carbonengine/parser/)                   |
| pathfinder               | A C++ library for route finding over EVE Online map data                                                           | [<img src="images/github-mark.svg" alt="GitHub repository" width="32" height="32">](https://github.com/carbonengine/pathfinder/)               |
| pdm                      | Platform Detection Module, an OS agnostic library for data collection                                              | [<img src="images/github-mark.svg" alt="GitHub repository" width="32" height="32">](https://github.com/carbonengine/pdm/)                      |
| pdm-proto-wrapper        | C++ library to wrap PDM output in protobuf                                                                         | [<img src="images/github-mark.svg" alt="GitHub repository" width="32" height="32">](https://github.com/carbonengine/pdm-proto-wrapper/)        |

| trinity                  | Rendering engine for the Carbon Game Engine                                                                        | [<img src="images/github-mark.svg" alt="GitHub repository" width="32" height="32">](https://github.com/carbonengine/trinity/)                  |
