Welcome to the Carbon Engine documentation. Here you learn what the Carbon Engine is and what sets it apart from
other game engines. You will also learn how you can [contribute](contributing.md) to it. Most importantly, however, this documentation also
teaches you [how to use it](getting_started.md).

## About Carbon Engine

Carbon is the game engine that powers EVE Online and EVE Frontier. As such, it is heavily leaning towards developing
MMO strategy games.

## About this documentation

Writing documentation for a complex project like the Carbon Engine is a monumental task and never truly complete. 
Therefore, this documentation continuously receives additions, edits, and corrections. Yet something may still be
unclear or amiss. If you think that is the case, please feel free to contribute via a pull request, or by raising an 
issue on [this repository](https://github.com/carbonengine/documentation).
