Here a reader should be informed about how to start developing _with_ carbon. That is, how to acquire 
[carbon components](components.md), how to [assemble a runtime environment](updatebinaries.md), and so on. 
All as a step-by-step guide. A possible example might be the simple window with debug info from the 2023 
Carbon summit slides.

This is explicitly not talking about [how to contribute to carbon](contributing.md), as that is a separate section.
